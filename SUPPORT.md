# Support

Remedence `0.x` is a local beta without a support SLA.

- Use GitHub issues for reproducible bugs and bounded feature requests.
- Include the commit/version, supported Node version, operating system, exact command, safe error text, and a minimal non-sensitive reproduction.
- Do not attach databases, raw evidence, customer data, environment files, tokens, or credentials.
- Use `SECURITY.md` for vulnerabilities.

Supported self-hosted service and hosted SaaS support channels, escalation, severity definitions, response objectives, and maintenance windows are not yet defined.
